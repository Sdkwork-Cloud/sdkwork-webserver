# SDKWork Webserver PC Documentation Contract

This package owns the public product documentation experience for SDKWork Web Server. It explains product capabilities and user workflows while leaving application data, deployment execution, SDK construction, authentication, and notification behavior with their owning modules.

The application root injects Portal, Console, and Messaging navigation, an optional viewer, and the supported agent display names. Root SDKWork specs remain normative; this module provides product guidance rather than a local standards copy.
